
Zombie Swarm Pro

A custom Counter-Strike 1.6 Android project based on Xash3D / CS16Client.

Game Modes

- Zombie Plague
- Zombie Swarm

Gameplay

- Offline mode with Bots
- Online multiplayer support
- XP and Level system
- VIP, Admin and Super Admin ranks
- Special weapons and abilities
- Zombie and Human classes
- Custom Zombie maps
- Separate progression and settings for each game mode

Zombie Swarm Features

- Jetpack
- Leap
- Flesh Throw
- Zombie infection abilities
- Human and Zombie classes

VIP Shop

- Parachute
- Pump Shotgun
- VIP chat tag

Admin Shop

- MP5 Pro
- Admin chat tag

Super Admin Shop

- M249 Pro
- Knife Pro
- All VIP and Admin privileges

Platform

- Android
- Xash3D / CS16Client
- Counter-Strike 1.6
- AMX Mod X compatible server architecture

Project Status

Work in progress.

This repository is for developing Zombie Swarm Pro. A ready-to-install APK is not available yet.
